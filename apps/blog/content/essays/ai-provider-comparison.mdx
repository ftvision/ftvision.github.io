# Writing

Gemini

- 文采很好
- 但是太趋炎附势
- 写的文章相对更有人情味

GPT
- 比较中立，具有一定独立思考的能力


Claude
- 思辨能力很强，写opinion文章，或者review/critize文章的思维Opus很不错。
- 但是文笔本身不太行

# Software Project

Gemini

- 对于前端和图片的理解很好，能够快速地理解用户对于前端不满的点在哪里。
- 执行很差，写不出太好的code

GPT / Codex
- 前端理解相对较好，有image-gen的skill直接拉爆前端mock
- computer use和browser use的集成很好。
- 需要high thinking


Claude
- 写程序水平很高
- 但是对前端的理解，尤其是用户为什么不满意前端，哪里不满意，相对比较蠢。导致用户和CC之间要沟通前端怎么修经常要很多轮，沟通成本很高。
- 但是如果能够准确地pinpoint问题所在，工程能力还是很强
