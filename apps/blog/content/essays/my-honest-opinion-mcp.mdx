## Tools for the agent harness -- MCP is here to stay

in 2026, we are not just talking about LLM, we are talking about shipping the agent harness. Now, how can you give new tools to your agent where you cannot control your agent harness. Come on, the reality is most people are using one agent harness or another. 

Here, MCP essentially has become the standard again.

Who will want to write MCP. 

- User of agent
- Service provider
- Agent developer

There are more and more people building on top of agent SDK. if you are using other people's agent SDK, MCP is almost the only way that user can provider tools on their side -- because it is a open protocol.
