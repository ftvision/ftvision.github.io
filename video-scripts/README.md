# Video Scripts

Turning Feitong's essays into videos for **YouTube · Bilibili · 小红书 · 抖音 · TikTok** — not a replacement for the blog, a second surface for the same ideas.

## Positioning
The channel sells one identity: a founding/senior **AI-builder engineer** (Project Sid, Fairies, Shortcut; ex-Google, ex-Citadel) delivering **contrarian, screenshot-backed takes**. The unfair advantage is real artifacts + earned credibility most talking-head channels can't fake.

## Conventions
- One essay → `NN-slug.en.md` (English master) + `NN-slug.zh.md` (Chinese).
- Each script = **one long cut** (YouTube EN / Bilibili ZH) **+ 2–3 single-idea vertical shorts** (抖音/小红书/TikTok).
- Language is an *origin* decision, not a translation toggle. For 2026 essays the full content is English, so **Chinese scripts are written FROM the English master**, not from the short `-zh` essay stubs.
