# 中文文笔：句法手术

先记三句，其余都是注脚：

1. **文笔不是气质问题，是句法问题。** 句子不好，不是灵气不够，是结构坏了。
2. **核心技术不是加，是减。** 加形容词、加排比、加典故，都是掩饰。真功夫在砍。
3. **改句子，不改观点。** 动句法，不动意思。信息一字不丢，立场一分不移。

中文的生命常态：措词简洁、句式灵活、声调铿锵（余光中）。顺此生态则健康，违拗则淤塞。手术的全部目的，是把句子改回这个生态。

## 三种任务

**写**：从零写中文。按下面的原理直接写；写完把初稿当病人，走一遍「六个动作」，砍掉三分之一再交。初稿偏长不是失误，是流程：先写足，再砍狠。

**改**：修改现成的中文。顺序：诊断（四病对号）→ 手术（六个动作）→ 自查清单。改完附一份病灶说明：挑三五处最重要的改动，讲清为什么，让作者下次自己能看见。别逐条罗列所有改动。

**评**：给文章体检、定级，不动稿子。按 [references/evaluation.md](references/evaluation.md) 走：量化体检 → 十查 → 定级，输出统一格式的评价单。用户问「这篇怎么样」「哪里有问题」时用这个，先评后改，别上来就动刀。

动手前读参考：

- [references/evaluation.md](references/evaluation.md)：评价规程，量化指标、十查、定级标准、评价单模板
- [references/rewrite-table.md](references/rewrite-table.md)：改写对照表，按词类分组，附完整段落示范
- [references/blocklist.md](references/blocklist.md)：屏蔽词表，逐类搜索用，附「何时可留」注记

## 诊断：四种病

### 病① 翻译腔（最普遍，最隐蔽）

英语句法渗进中文。不难看，只是稀：字多，力弱。
标志：万能动词（作出决定、进行讨论）、名词化（可读性、力度）、抽象名词当主语、「的」成灾、被动式、长定语前置、「之一」「当……的时候」。

### 病② 公文腔（党八股）

「高度重视」「切实」「扎实」「进一步」「不断增强」。
测试：逐字改成大白话。改不出来，因为它什么也没说。**党八股的功能不是表达，是让空话看起来像话。** 四种病里唯一会摧毁思考的一种：它一旦进来，作者就再也发现不了自己没有想法。遇到它，先问这句话到底说了什么；答案常常是「什么也没说」，那就整句删。

### 病③ 文艺腔（最危险，因为它像好文笔）

排比、感叹、历史抒情、形容词雪崩、金句癖。用抒情代替说事，给一切打柔光。警句需要姿态，姿态成瘾，就再也写不了平实的句子。
改法第一步：问这段到底说了什么事。把事说出来，抒情自然掉光。

### 病④ 学术黑话

「话语」「场域」「建构」「张力」「吊诡」「主体性」。显得深刻，代价是句子不再指向任何具体的东西。改法：逼它说出具体所指。

## 原理：为什么这么改

1. **竹子，不是葡萄串。** 英语句法是葡萄串：一根主干，从句挂满。中文是竹子：一节一节推下去，每节自足。长定语塞进名词前面，句子就断气。
2. **意合，不是形合。** 英语靠 and / because 显性连接，中文靠语序。「因为下雨，所以我没去」→「下雨，我没去」。关联词能省则省，省不掉的才是真需要的。
3. **动词本位。** 中文是动词的语言。翻译腔的本质是把动词压成名词，再用万能动词抬起来：「对方案进行了修改」→「改了方案」。凡是「万能动词＋名词」，都能还原成一个实动词。
4. **节奏用耳朵查。** 中文有声调，句子有呼吸。凡是默读到一半要换气、要回头的句子，就是坏句子，没有例外。眼睛看不出节奏，耳朵可以。

## 手术：六个动作

按顺序执行，每个动作过一遍全文。

1. **屏蔽词扫描。** 按 [references/blocklist.md](references/blocklist.md) 逐类搜索，逐个过堂。默认删改，除非删掉意思真的会变。
2. **动词化。** 搜「进行、作出、做出、造成、给予、予以、加以、实现、具有、得到、受到」，每一个换成实动词。「失事造成九十八人死亡」→「失事，死了九十八人」。
3. **删「的」。** 目标删掉一半，不许损失意思。连环「的」可改「而」：「参差的斑驳的黑影」→「参差而斑驳的黑影」。这是见效最快的一刀。
4. **拆定语，改后饰。** 超过 12 字的前置定语，一律拆成独立小句，跟在名词后面：「我见到一个陌生男人，长得像你兄弟。」后饰句是开放句，可以一路加下去；前饰句是关闭句，一长就断气。
5. **节奏默读。** 全文在心里读一遍。要换气、要回头的句子，重写。
6. **砍三分之一。** 最后通读，整体砍掉三分之一的字，不许损失任何意思。答案几乎永远是砍得动。

## 分寸：五条防过火

规则用力过猛，会制造另一种病。

- **西化不全是病。** 缓慢适度的西化难以避免，高妙的西化可以截长补短。要杀的是恶性西化：化简为繁、以拙代巧。判断标准是改完有没有更简洁灵活，不是见「洋」就杀。
- **简洁不是电报腔。** 「他研究 AI 安全五年了。现在这套监管，他不信。」狠，但一篇文章全是这种句子就成了装腔。长短相间，句子才有呼吸；该慢的地方允许慢。
- **屏蔽词是过堂，不是死刑。** 「他被捕了」的「被」没有病；「其实」偶尔转折可留，连用即删。每个词单独审，别机械替换。
- **成语是本钱，不是罪。** 处处仰赖成语，等于用古人的脑想、古人的嘴说；但一个成语顶一句话时就该用：「一言难尽」胜过「不是一句话就能说清楚的」。
- **别把说事改成金句。** 手术的终点是平实、清楚、有力，不是句句可摘抄。改完读起来应该像好的说话，不像表演。

标点同理：少用破折号和分号，多用句号和逗号；感叹号基本不用。变化要有常态衬托才显得出来：先守常态，再谈破格。

## 语感基准

往哪儿改，心里要有原型：

- **汪曾祺**：白描。名词和动词扛起全部重量，几乎不用形容词。
- **阿城**：硬、短、准。每句话不肯多一个字。
- **杨绛**：用极度克制写极度悲痛。情绪越大，字越冷。
- **王小波**：用推理推进段落，不用情绪。

反面原型，见即改：余秋雨式历史抒情、蒋勋式柔光、公众号体（短句分行、煽情、「记住」「真的」）。

## 委托 Subagent

skill 不会自动进入 subagent 的上下文。派 subagent 评价或修改中文时（多篇并评、长文分章、workflow 审稿），任务提示里必须写明：

1. 开工前先读文件，给出完整路径：本 SKILL.md，加 `references/evaluation.md`（评价任务）或 `references/rewrite-table.md` 与 `references/blocklist.md`（修改任务）。评价规程是自足的，subagent 不需要本对话的任何上下文。
2. 评价任务：按 evaluation.md 的评价单模板输出，一篇一单。格式统一，汇总时才能对着比。
3. 修改任务：按六个动作的顺序执行，输出改稿加病灶说明，声明字数降幅。
4. 提醒 subagent 读「分寸」一节。没读过分寸的 subagent 最容易把稿子改成电报腔。

多篇并行时一篇一个 subagent；汇总时按定级排序，别把十份评价单原样堆给用户。

## 定稿自查清单

交稿前过一遍：

- [ ] 全文默读过了吗？有没有要换气、要回头的句子？
- [ ] 「的」还能再删吗？
- [ ] 还有「万能动词＋名词」吗？
- [ ] 还有超过 12 字的前置定语吗？
- [ ] 还有抽象名词当主语吗？
- [ ] 关联词还能省几个？
- [ ] 形容词副词删完，意思变弱了吗？（通常变强）
- [ ] 有没有哪句话删掉后全文毫无损失？（有就删）
- [ ] 有没有一段在抒情而不是说事？
- [ ] 把修辞全去掉，骨头还成立吗？
- [ ] 整体还能砍三分之一吗？（几乎永远能）

> 病句（41 字）：作为一个在过去五年中持续关注人工智能安全问题的研究者，他对于当前监管框架的有效性表达了深切的怀疑。
>
> 改（19 字）：他研究 AI 安全五年了。现在这套监管，他不信。
