# 改写对照表

按词类分组，与 [evaluation.md](evaluation.md) 的十查一一对应。每条先认病，再下刀。

## 动词：弱动词还原

| 病句 | 改 |
|---|---|
| 作出决定 | 决定 |
| 进行讨论 | 讨论 |
| 给予帮助 | 帮助 |
| 加以说明 | 说明 |
| 失事造成九十八人死亡 | 失事，死了九十八人 |
| 对国际贸易问题进行了详细的研究 | 详细研究了国际贸易问题 |
| 进行了一次深入的讨论 | 深谈了一次 |

## 动词：被动改主动

「被」不是中文被动的唯一写法。受难、遇害、挨打、遭殃、经人指点、为世所重、当选、获准，都是被动义；受事主语句（「糖都吃光了」「稿写了一半」）更是中文天然的被动。

| 病句 | 改 |
|---|---|
| 这个问题被广泛地认为是具有高度复杂性的 | 大家都觉得这事复杂 |
| 这本书受到了广泛的欢迎 | 这本书很受欢迎 |
| 他被选为议长 | 他当选议长 |
| 他不被准许入学 | 他未获准入学 |
| 我不会被你这句话吓倒 | 你这句话吓不倒我 |
| 他被怀疑偷东西 | 他有偷东西的嫌疑 |

## 名词：名词化与伪术语

| 病句 | 改 |
|---|---|
| 加大支持力度 | 多支持 |
| 具有可读性 | 好读 |
| 这本传记的可读性颇高 | 这本传记很好看 |
| 具有很高的知名度 | 很有名 |
| 更具前瞻性 | 更有远见 |
| 难度很高的技巧 | 很难的技巧 |
| 他是热情型的人 | 他热情 |
| 富于爱国主义的精神 | 富于爱国精神 |
| 系统性地推进 | 一步步来 |

## 名词：主语归位

中文以具体名词（尤其是人）或一件事做主语，不用抽象名词，也不把短句「的」化成名词。

| 病句 | 改 |
|---|---|
| 沟通的缺乏导致了误解的产生 | 两边不通气，就误会了 |
| 他的收入的减少改变了他的生活方式 | 他收入减少，改变了生活方式 |
| 横贯公路的再度坍方，是今日的头条新闻 | 横贯公路再度坍方，是今日的头条新闻 |
| 书籍的选购，只好委托你了 | 选购书籍，只好委托你了 |

## 代词复数：「们」

| 病句 | 改 |
|---|---|
| 读者们、朋友们 | 读者、朋友（中文靠语境表复数） |
| 人们 | 人人、大家、世人、众人 |
| 民众们、听众们 | 民众、听众（「众」「们」并用，不通） |
| 所有的乘客们 | 所有乘客（已是复数，不必再标） |

## 连接词：and 意识

中文并列任其并列：柴米油盐酱醋茶、思前想后。必须连接时用「而」，它兼有 and 与 but 之功用；「及」在正文里基本要不得。

| 病句 | 改 |
|---|---|
| 因为下雨，所以我没去 | 下雨，我没去 |
| 起步更早及迈步更快 | 起步更早，迈步也更快 |
| 慢及可靠 | 慢而可靠 |
| 柴、米、油、盐、酱、醋以及茶 | 柴米油盐酱醋茶 |

## 介词：画蛇添足

| 病句 | 改 |
|---|---|
| 关于这个问题，我有一些想法 | 这事我有想法 |
| 在有关环境污染的各种问题上 | 谈环境污染 |
| 由于他的家境贫穷，使得他只好休学 | 他家境贫穷，只好休学 |
| 由于好奇心的驱使，我看了一眼 | 出于好奇，我看了一眼 |

## 副词：「地」与「成功地」

成语本可作动词或副词，挂「地」反而降格；删「地」代以逗点，句法就松了筋骨。

| 病句 | 改 |
|---|---|
| 国父成功地推翻了满清 | 国父推翻了满清（推而翻之，就是成功了） |
| 大家苦中作乐地大唱民谣 | 大家苦中作乐，大唱民谣 |
| 老师苦口婆心地劝了他半天 | 老师苦口婆心，劝了他半天 |

## 定语：「的」与前饰后饰

后饰句是开放句，可以一路加下去；前饰句是关闭句，一长就断气。文言深谙此道：「广为人长，猿臂，其善射亦天性也。」

| 病句 | 改 |
|---|---|
| 一个善良的、温和的、有责任心的人 | 这人善良，温和，靠得住 |
| 参差的斑驳的黑影 | 参差而斑驳的黑影 |
| 一个在过去五年中持续关注 AI 安全问题的研究者 | 这人研究 AI 安全，五年了 |
| 我见到一个长得像你兄弟说话也像他的陌生男人 | 我见到一个陌生男人，长得像你兄弟，说话也像他 |
| 白色的鸭 | 白鸭 |

## 句式框架：「之一」「作为」「当…时候」

「最……之一」抬到至高又稍加低抑，兜一个大圈子，等于没说。范围明确的「竹林七贤之一」可用；范围不明的「名著之一」是蛇足。

| 病句 | 改 |
|---|---|
| 他是最伟大的作家之一 | 最伟大的作家里有他 |
| 红楼梦是中国文学的名著之一 | 红楼梦是中国文学名著 |
| 作为竹林七贤之一的刘伶以嗜酒闻名 | 刘伶是竹林七贤之一，以嗜酒闻名 |
| 我最喜欢的导演其中之一 | 我最喜欢的导演里有他 |
| 当我回到家的时候，天已经黑了 | 我到家，天黑了 |
| 如果你同意的话 | 你要是同意 |

## 公文腔：先问说了什么

| 病句 | 改 |
|---|---|
| 切实增强用户体验 | （删。它没说任何事） |
| 我们要高度重视用户反馈 | （翻成大白话试试。翻不出来就整句删） |

## 段落示范

### 示范一：翻译腔（长定语＋抽象名词）

> **病句（41 字）**
> 作为一个在过去五年中持续关注人工智能安全问题的研究者，他对于当前监管框架的有效性表达了深切的怀疑。
>
> **改（19 字）**
> 他研究 AI 安全五年了。现在这套监管，他不信。

短了一半，狠了三倍。手术路径：「作为……的」框架整个拆掉；长前饰改成独立小句（后饰）；「表达了深切的怀疑」还原成实动词「不信」；「有效性」蒸发。

### 示范二：翻译腔＋公文腔（科技评论常见）

> **病句（54 字）**
> 随着大语言模型能力的不断提升，越来越多的开发者开始对如何将 AI 有效地集成到现有工作流中这一问题进行深入的思考。
>
> **改（26 字）**
> 大模型越来越强，开发者都在想同一件事：AI 怎么进工作流。

「随着……的不断提升」是翻译腔开场白，改成一个短句陈述；「对……这一问题进行深入的思考」是弱动词裹名词团，还原成「在想」。

### 示范三：文艺腔（先问它说了什么）

> **病句**
> 时间是最公平的裁判，它会温柔而坚定地筛选出真正有价值的东西，让浮华褪色，让真金闪光。
>
> **改**
> 好东西留得下来，坏东西会被忘掉。

改文艺腔的第一步不是改字，是问：这段到底说了什么事？答案往往薄得吓人。把那件事平实地说出来；如果说出来发现是句废话，整段删。

### 示范四：学术黑话（逼它说出具体所指）

> **病句**
> 这一话语建构过程凸显了平台与创作者之间的结构性张力，并在多个维度上重塑了内容生产的场域逻辑。
>
> **改**
> 平台和创作者要的东西不一样。这个矛盾正在改变内容的生产方式。

「张力」是什么张力？「场域逻辑」是什么逻辑？逼原句交出具体所指，交不出来的词全删。

## 下刀顺序

一段病得重的文字，按这个顺序改，互不打架：

1. 先删整句废话（公文腔、无内容抒情）
2. 再拆长定语、拆葡萄串长句，前饰改后饰
3. 然后动词化、删「的」、杀屏蔽词、清「地」和「及」
4. 最后默读校节奏，长短句错开
