# 文笔评价规程

本文件自足：评价一篇中文，只需本文件加 [blocklist.md](blocklist.md)；要动手改，再读 [rewrite-table.md](rewrite-table.md) 和 SKILL.md。病理学出自余光中《怎样改进英式中文——论中文的常态与变态》与思果《翻译研究》。

评价的对象是文笔，不是观点。观点好坏另议，这里只问一件事：句子健康吗？衡量标准是中文的生命常态：措词简洁、句式灵活、声调铿锵。

流程三步：量化体检 → 十查 → 定级。统计前先剔除 frontmatter、代码块、英文引文和 URL。

## 第一步：量化体检

先数数。数字不判死刑，只指认可疑地带；判罪要靠第二步摘出的病例。用 `grep -o 的 file | wc -l` 一类的命令代劳，别手数。

| 指标 | 算法 | 健康 | 偏高 | 病 |
|---|---|---|---|---|
| 「的」密度 | 「的」字数 ÷ 总字数 | < 3% | 3–4.5% | > 4.5% |
| 弱动词 | 「进行/作出/做出/造成/加以/予以/给予」次数，每千字 | 0–1 | 2–3 | ≥ 4 |
| 被动「被」 | 「被」次数，每千字 | ≤ 1 | 2–3 | ≥ 4 |
| 公文腔命中 | blocklist 公文腔类命中次数，全文 | 0 | 1 | ≥ 2 |
| 平均句长 | 以句号问号叹号切分，总字数 ÷ 句数 | ≤ 35 | 35–50 | > 50 |
| 超长句 | 单句超 70 字的句数 | 0 | 1–2 | ≥ 3 |
| 长前饰 | 超 12 字的前置定语个数 | 0–1 | 2–3 | ≥ 4 |
| 能砍率 | 抽两三段动手改一遍，算字数降幅 | < 15% | 15–25% | > 25% |

阈值按现代散文校准，是参考带不是铁律：对话体「的」偏高正常，学术综述句子偏长正常。拿不准就看改后对比：改完明显更好，原文就是有病。

## 第二步：十查

词类七查治翻译腔，内容三查治另外三病。每查做三件事：摘病例（1–3 句原文）、判轻重、给改法。没病就写「无恙」，别硬凑。

### 词类七查（翻译腔）

1. **名词查**。抽象名词做主语？（「沟通的缺乏导致误解」）短句主语被「的」名词化？（「横贯公路的再度坍方」应为「横贯公路再度坍方」）伪术语？（知名度、可读性、前瞻性、难度很高、热情型）「主义」滥用？（爱国主义精神 → 爱国精神）
2. **动词查**。弱动词裹抽象名词？（进行讨论、作出贡献、造成死亡）被动泛滥？该用「当选、获准、遇害、经人指点、为世所重」的地方是不是一律「被」？
3. **代词复数查**。「们」滥用？「人们」出现了吗？（改：人人、大家、世人）「众」「们」并用？（「民众们」不通）已含复数还画蛇添足？（「全校的师生」不必「师生们」）
4. **连接词查**。「及」「以及」进了正文？并列成分被「和、与」硬串？（中文并列任其并列：柴米油盐酱醋茶）「而、并、而且」还活着吗？必须连接时用「而」，不用「及」。
5. **介词查**。「关于、有关、对于、就…而言、在…方面/上/里面」有多少画蛇添足？「由于…使得」双重交代？（「由于家境贫穷，使得他休学」→「他家境贫穷，只好休学」）
6. **副词查**。成语后面挂「地」？（「苦心孤诣地」：删地，代以逗点）「成功地」？（推翻了就是成功了，不必再说）
7. **定语查**。「的」连环？（「弯弯的杨柳的稀疏的倩影」）超 12 字前饰？该后饰不后饰？后饰句是开放句（「我见到一个陌生男人，长得像你兄弟」），前饰句是关闭句，一长就断气。

### 内容三查（公文腔、文艺腔、学术黑话）

8. **空话查（公文腔）**。可疑句逐字翻成大白话。翻得出来，是文风病，重说；翻不出来，是没有内容，整句删。「切实增强用户体验」属于后者。
9. **说事查（文艺腔）**。抒情段落问一句：这段到底说了什么事？说得出，把事写出来，抒情自然掉光；说不出，删段。排比、感叹号、形容词雪崩、金句癖都归此查。
10. **所指查（学术黑话）**。「张力、场域、建构、维度、语境」逐个逼问：具体指什么？交得出所指，换成那个具体说法；交不出，删。

## 第三步：定级

| 级 | 判据 |
|---|---|
| **A 健康** | 量化全绿或近绿；十查无重病；能砍率低于 15%。有自己的节奏和语感。 |
| **B 轻症** | 一两类指标偏高，局部翻译腔，骨架还是中文的。过一遍屏蔽词加删「的」即愈。 |
| **C 显性西化** | 多类超标；弱动词、「的」、长前饰成片；句子普遍偏长断气。需要完整六动作手术。 |
| **D 恶性西化** | 公文腔或空话成段，或通篇葡萄串长句。修改成本接近重写；建议列骨架重写。 |

定级同时必须点出 1–3 处**好句**：成语用得准、后饰句舒展、节奏漂亮、白描有力的地方。评价不是只见病不见文；好句是作者该保住的本钱，也让定级有对照。

## 评价单模板

输出一律用这个格式。多篇并评时一篇一单，汇总才对得上。

```
# 文笔评价：<篇名>

**定级：<A/B/C/D>**：<一句话总评>

## 量化体检
<指标表，标出超标项；注明全文字数>

## 病灶（按轻重排序，最多五处）
每处：查号＋原句摘录＋判语＋改写示范

## 好句（1–3 处）
原句＋好在哪

## 修改路线
按下刀顺序给建议：先删什么，再拆什么，最后校什么。估计能砍率。
```

## 评价的分寸

- 数字超标不等于病，摘不出病例就不算数。反过来，数字全绿也可能是 D：空话可以一个屏蔽词都不带。内容三查优先于词类七查。
- 病灶最多报五处，按轻重排。报二十处等于没报。
- 改写示范必须真改，短而狠，让作者看见差距。判语没有示范，等于医生只说「有病」。
